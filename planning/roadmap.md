# NPC Beta Roadmap

## Phase 1 — Foundation

- Establish the project structure and contribution workflow.
- Define editorial standards and a shared tag vocabulary.
- Create a responsive static catalog shell.
- Add empty character and location indexes with documented schemas.

## Phase 2 — First collection

- Draft and review the first set of characters and locations.
- Add optimized, consistently sized images.
- Publish searchable cards from the JSON indexes.
- Add detail pages or views for individual entries.

## Phase 3 — Discovery

- Add filters for tags, roles, regions, and status.
- Support relationships between characters and locations.
- Improve keyboard navigation and screen-reader announcements.
- Add automated checks for content schema and broken links.

## Later ideas

- Community submission templates.
- Versioned lore and revision history.
- Downloadable data exports.
- Optional map and relationship visualizations.
