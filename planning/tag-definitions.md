# Tag Definitions

Tags provide a small, predictable vocabulary for browsing the catalog. Use
lowercase kebab-case, choose only tags that materially help discovery, and avoid
creating synonyms.

## Character tags

| Tag | Use when |
| --- | --- |
| `ally` | The character usually assists the player or central cast. |
| `antagonist` | The character actively opposes the player or central cast. |
| `merchant` | Trading goods or services is a primary function. |
| `quest-giver` | The character initiates or advances quests. |
| `wanderer` | The character is not tied to one permanent location. |
| `mysterious` | Concealed identity or motives are a defining trait. |

## Location tags

| Tag | Use when |
| --- | --- |
| `settlement` | The location is a populated town, village, or city. |
| `wilderness` | The location is primarily an undeveloped natural area. |
| `landmark` | The location is a distinct point of interest. |
| `dangerous` | Visiting presents an unusually high level of risk. |
| `hidden` | Discovery or access is intentionally difficult. |
| `hub` | The location connects several routes, services, or story lines. |

## Adding a tag

Propose a tag in a content review. Define one specific discovery purpose, check
that an existing tag does not cover it, and add the definition here before using
the new value in published data.
