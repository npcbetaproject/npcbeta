Norzor Stormfield

Dwarf · Blacksmith · Pride in every rivet

Description

Proud and dependable, Norzor judges work by how well it survives hard use. A braided auburn beard and a scarred leather apron frame a craftsperson whose promises are as solid as the tools leaving the forge.

At the table

Test the weight of anything handed over. Praise good workmanship plainly; grumble at shortcuts, then explain how to fix them.

Adventure hook

A shipment of ore contains a metal that will not cool. Norzor wants its source investigated before anyone uses it.
